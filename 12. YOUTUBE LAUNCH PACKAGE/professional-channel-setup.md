# Professional Channel Setup

Use this before the first public launch and before any YPP review.

## Channel Positioning

Primary identity:

`Tesla Mandela Effects is a cinematic historical docufiction series about Nikola Tesla, archival mystery, speculative reconstruction, and anomalies in the historical record.`

Do not lead with:

- conspiracy
- proof
- exposed
- hidden truth
- factual claims that fictional sources are verified

The channel should look like an original scripted audio-docufiction brand, not a repost channel, AI content farm, or conspiracy channel.

## About Page Copy

Use this as the first version:

`Tesla Mandela Effects is a cinematic historical docufiction series exploring Nikola Tesla, archival mystery, speculative reconstruction, and anomalies in the historical record. Each long-form episode blends documented history with fictional sources created for narrative purposes. The series is storytelling, not a factual documentary.`

Optional second paragraph:

`Start anywhere. Each episode is standalone, built as a one-hour-plus immersive audio film for YouTube.`

## Visual Identity

- Profile image: Tesla/monogram mark, high contrast, readable at small size.
- Banner: series title plus three-episode launch signal; no tiny episode text.
- Playlist cover: use the strongest shared visual language from the thumbnails.
- Thumbnail system: one cinematic image, 2-4 words, no red arrows, no stamped `proof`, no tabloid marks.

## Channel Defaults

- Category: `Film & Animation`.
- Audience: `No, not made for kids`.
- Comments: on, with held-for-review filter if needed.
- Embedding: on.
- Notify subscribers: on for these three launch uploads.
- Shorts remixing: decide intentionally; default off if you want tighter brand control.
- Altered/synthetic disclosure: yes for these episodes because realistic generated/altered scenes and synthetic narration are part of the format.

## Monetization Readiness

Before publishing, confirm in YouTube Studio:

- 2-Step Verification is enabled.
- Advanced features are enabled.
- No active Community Guidelines strikes.
- Earn tab status is understood.
- If YPP eligible: Watch Page Ads module accepted, AdSense connected, monetization on for each upload.
- If Self-Certification appears: rate accurately and consistently.

Do not publish monetized uploads while Checks are still unresolved if the goal is maximum launch revenue. Wait for the copyright/ad-suitability result, then decide.
