connectors, public web research, and local file checks each prove different
things. Use the external-access operational check before claiming control.

## Chrome / Studio Workflow

Use Chrome when the task needs the user's logged-in YouTube Studio session,
brand/channel selection, monetization UI, checks UI, upload defaults, playlists,
captions, end screens, or channel setup.

Before action:

- Confirm visible channel name, handle, and channel ID if shown.
- Confirm the user-selected account/channel is Tesla Mandela Effects, not the
  personal account unless that is the owner account used to manage the channel.
- Stop before final publish or irreversible account changes unless the user
  explicitly approved that exact action.

Do not handle passwords, 2FA, recovery codes, cookies, session storage, payment
details, or AdSense banking details.

## Official API Workflow

Use official API/OAuth when the task needs durable automation, upload scripts,
channel reads, video metadata reads/writes, Analytics, or Reporting.

Before upload automation:

- Verify Google Cloud project and enabled YouTube APIs.
- Verify OAuth scopes from current official docs.
- Run a safe channel read against the intended channel.
- Record the channel identity proved by API.
- Never print secrets, tokens, authorization codes, raw credentials, or refresh
  tokens.

## Per-Episode Review Contract

For each episode, produce a short review with:

- upload file path and duration/source status;
- thumbnail path and visual promise;
- title review for click clarity and exact entity identity;
- first two description lines;
- docufiction disclaimer strength;
- chapter/key moment quality;
- caption/transcript entity risks;
- tags as misspellings/entity variants only;
- AEO/GEO answer blocks or companion-page needs;
- monetization/risk notes;
- exact edits recommended before upload.

Do not rubber-stamp existing metadata. Treat existing files as draft assets to
review against current YouTube rules and the actual channel surface.

## Launch Guardrails

- Do not upload the wrong Episode 3 V2 32-minute file.
- Do not publish before copyright/checks/processing are reviewed unless the
  user explicitly accepts that risk.
- Do not use Premiere for 1440p masters unless a separate 1080p Premiere file
  is prepared.
- Do not upload more than three notification-eligible uploads/live streams in a
  24-hour window for this launch.
- Do not frame fabricated sources as factual evidence.
- Do not stuff tags or hashtags into descriptions.
