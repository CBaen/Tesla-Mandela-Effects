Use current official sources before making claims about YouTube uploads,
notifications, monetization, metadata, chapters, thumbnails, API scopes,
Analytics, or Reporting.

## Current Rules To Preserve

- Upload/live notifications are capped per channel in a 24-hour window.
- Tags can help misspellings and variants, but title, thumbnail, description,
  and content are more important discovery surfaces.
- Manual chapters need timestamp rules and may require advanced features.
- Custom thumbnails require account verification and must follow Community
  Guidelines.
- YouTube search considers relevance, engagement, and quality; metadata is only
  one part of relevance.
- YPP requires policy compliance, region eligibility, no active strikes,
  2-Step Verification, advanced features access, AdSense setup, and threshold
  eligibility/review.
- YouTube API upload, Analytics, Reporting, Studio UI, and monetization policy
  are separate lanes.

## Source Discipline

If a source changes or conflicts with the launch package:

1. Preserve the conflict.
2. Quote or summarize the current official source with URL/date.
3. Update the launch recommendation.
4. Do not silently overwrite existing strategy.
