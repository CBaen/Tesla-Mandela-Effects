# YouTube Studio Access Workflow

I do not currently have standing access to the YouTube account. When the user is ready, use a logged-in browser session.

## Safe Login Flow

- The user opens YouTube Studio and logs in personally.
- The user handles password, 2FA, recovery prompts, and account choice.
- I do not ask for or store passwords, 2FA codes, recovery codes, cookies, or tokens.
- After login, I can help inspect and configure the account through the visible YouTube Studio session.

## What To Inspect First

1. Confirm channel:
   - Channel name
   - Handle
   - Profile image
   - Banner
   - About description
   - Country/region

2. Confirm eligibility:
   - Earn tab status
   - Subscriber count
   - Valid public watch hours
   - YPP eligibility
   - Any active strikes
   - 2-Step Verification
   - Advanced features access
   - AdSense setup

3. Confirm monetization modules if eligible:
   - Watch Page Ads
   - Shorts Feed Ads
   - Commerce Product Module / fan funding if available

4. Confirm upload defaults:
   - Category
   - License
   - Comments
   - Embedding
   - Captions language
   - Notify subscribers default
   - Shorts remixing default

5. Upload workflow:
   - Upload Episodes 001 and 002 as private/scheduled.
   - Enter metadata from the launch package.
   - Set altered/synthetic disclosure accurately.
   - Wait for checks before publishing.
   - If monetized, add mid-roll slots and keep automatic slots on.
   - Add to playlists.

## What I Can Manage After Login

- Upload metadata entry.
- Playlist creation.
- Channel description/keywords.
- Upload defaults.
- Scheduled visibility settings.
- Caption upload/review.
- End screens and cards.
- Monetization status inspection.
- Checks page review.
- Analytics review after launch.

## What I Will Not Do

- Handle passwords or 2FA.
- Change payment or AdSense banking details.
- Accept monetization contract terms without explicit user approval.
- Publish a video before checks are done unless the user explicitly chooses that risk.
- Upload the wrong Episode 3 file.
